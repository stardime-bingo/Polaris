# Security

The current Polaris 1.4.x source is the focus of maintenance. There is no guaranteed response SLA.

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/stardime-bingo/Polaris/security/advisories/new), rather than posting an exploit or private goal data in a public issue.

Include the affected version/commit, macOS version, reproduction steps using fictional data, and the expected impact. Do not include credentials, personal reminder exports, account identifiers or unrelated system logs.

Data-loss, unintended Reminders writes, authorization-boundary failures and accidental disclosure of local data are especially relevant. Read [PRIVACY.md](PRIVACY.md) for the intended data flow.

Local builds use ad-hoc signatures. Source availability and a passing CI build do not mean a binary is Developer ID-signed or notarized. Obtain source and any future releases only from this repository or an explicitly trusted distributor.
